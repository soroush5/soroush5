## Projects

[Dynamic-RTL](https://github.com/soroush5/Dynamic-RTL): a browser extension for Chrome, Firefox and Safari.
It finds Persian or Arabic text on a page and switches it to right-to-left with the Vazirmatn font.
Handy on chat apps, X and any page that mixes Persian and English.
